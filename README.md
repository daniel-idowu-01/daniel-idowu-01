## Selected Work

---

### 🏦 LendStack
**Full-stack Nigerian consumer lending platform**

A production-grade loan management system built for the Nigerian market — CBN-compliant, multi-lender, and designed to handle the full complexity of personal lending operations.

- 14-state loan lifecycle engine with enforced transitions and tamper-proof audit trail
- Rule-based credit scoring, guarantor consent workflows, and collateral verification
- CBN-aware compliance: runtime-editable interest caps, reducing-balance amortisation, BVN-gated progression
- NDPC-compliant AES-256-GCM PII encryption with log-layer masking
- Paystack repayments with HMAC-SHA512 webhook verification and idempotent settlement
- Lender-matching engine splitting loans by risk appetite and exposure headroom

`Java` `Spring Boot` `Next.js` `PostgreSQL` `Paystack` `Docker`

### 🤖 YAAS — Modular AI Assistant
**Multi-agent orchestration backend**

Distributed AI backend powering 15+ capabilities — summarization, email parsing, scheduling, meeting notes — with a task orchestration engine that routes dynamically using contextual memory and vector search.

- 92% intent classification accuracy across NLP pipelines
- Vector-based dynamic routing via Pinecone
- Real-time chat and meeting processing via WhatsApp Cloud API and Google Meet

`Node.js` `FastAPI` `LangChain` `Pinecone` `HuggingFace`

### 📱 Vendra
**WhatsApp-first business OS for African SMEs**

A business operating system that lives entirely in WhatsApp — inventory, invoicing, debt tracking, analytics, and AI-assisted business queries, built for the way African SMEs actually work.

- Natural-language business queries across inventory and sales data
- AI-powered assistants for workflow automation and real-time reporting
- Scalable backend with Redis caching and webhook-driven event processing

`NestJS` `PostgreSQL` `Redis` `Docker` `WhatsApp API`
